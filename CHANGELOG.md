# Changelog

## 0.1.0 — 2026-11-10

Initial implementation on `main` (a GitHub release/tag is not implied).

- Native Markdown views and concurrent streaming sessions.
- Incremental parsing, incomplete-syntax healing and strict finalization.
- Smooth reveal and automatic, coalesced UI wake-ups.
- Highlighted, selectable, copyable and collapsible code blocks.
- Virtualized message history with stable identities and native scroll anchoring.
- Theme, link, image, code, math and HTML extension APIs.
- Native desktop playground, headless smoke checks and generated light/dark screenshots.
- Parser differential tests, session race/reset tests, native interaction tests and benchmarks.
- English/Chinese documentation, feature comparison, CI and MIT licensing.
