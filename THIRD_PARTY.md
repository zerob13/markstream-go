# Third-party software and design references

- **MyGo**, https://github.com/egoist/mygo, MIT, copyright EGOIST and contributors. Imported through Go modules, including its native UI, editor highlighting and incremental Markdown parser. Its license is distributed with the module; see `go.mod` / `go.sum` for the exact version.
- **markstream-vue**, https://github.com/Simon-He95/markstream-vue, MIT, copyright Simon He and contributors. Architectural reference for streaming Markdown, stable completed blocks, progressive rendering and extension fallback. No Vue or parser source was copied into this repository.
- **Lobe MyGo**, https://github.com/lobehub/lobe-mygo, MIT, copyright LobeHub and contributors. Architectural reference for Go-native UI components and a native catalog. No Lobe component source was vendored.

Transitive dependencies retain their respective licenses. `go list -m all` lists the resolved modules. The MyGo module depends on packages including purego, go-text/typesetting, x/image and x/text; application builds additionally include MyGo's platform and media dependencies.

## Independent renderer and rich worker

The Markdown control implementation is owned by markstream-go (`view.go`,
`nodes.go`, `renderer.go`, `inline.go`, `reveal.go`, `virtual.go`). It does not
import or vendor MyGo's Markdown widget. The low-level
`github.com/egoist/mygo/ui/markdown/parser` dependency supplies incremental
CommonMark/GFM syntax; Markstream converts that syntax into its own node model.
MyGo's UI/editor primitives supply drawing, text editing and native diff layout.

The optional `rich` package embeds the renderer engines and fonts generated by
`tools/renderer/build.mjs`. Exact versions and integrity values are locked in
`tools/renderer/package-lock.json`; bundled notices are in
`rich/assets/THIRD_PARTY.txt` and the generated `*.LEGAL.txt.gz` assets.

- Mermaid 11.12.2, KaTeX 0.16.25, DOMPurify 3.3.3 and AntV Infographic 0.2.3 retain their upstream licenses (notices included with assets).
- D2.js 0.1.33 retains MPL-2.0; the license is in `rich/LICENSE.d2`. Its corresponding upstream source is https://github.com/terrastruct/d2/tree/581c91096b62d644fb5168313142c836b7e68e74/d2js . D2 is an unmodified third-party engine, bundled by the documented asset build script.
- kyokomi/emoji v2.2.13 supplies the optional emoji shortcode dictionary under MIT.
- chromedp and cdproto supply the isolated Chromium worker protocol under their upstream licenses.

The Go library's MIT license does not relicense third-party engines or fonts.
